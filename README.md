# Child Welfare Management System (CWMS)

## 📌 Overview

The Child Welfare Management System (CWMS) is a web-based application designed to support UNICEF Rwanda in managing child welfare cases. The system centralizes case reporting, tracking, and service coordination across multiple departments such as health, education, and emergency response.

---

## 🎯 Objectives

* Improve coordination between social workers, NGOs, and administrators
* Enable efficient child case tracking and management
* Provide real-time data for decision-making
* Ensure proper documentation of child welfare activities

---

### Backend

---

## 🏗️ System Architecture

The system follows a layered architecture:

* Presentation Layer (Frontend UI)
* Business Logic Layer (Controllers)
* Data Layer (PostgreSQL Database)

---

## 🚀 Features

* Register child
* Report abuse case
* Create and manage cases
* Add health records
* Add education records
* Manage emergency alerts
* Generate reports

---

## 🐳 Docker Setup

### Build and Run

```bash
docker-compose up --build
```

### Access

* Backend API: http://localhost:3000
* Frontend: open `frontend/html/register.html`
